# V5 SWE and Data layout presets

The renderer lives in `src/lib/templates/v5.ts`. It retains the existing local V5 master's article size, fonts, margins, section order, spacing, project heading macro, bullet macros, hyperlink configuration and Unicode text extraction setup. SWE and Data share the formatting master; per-role `includeSwe` and `includeData` determine work-history composition. Neither preset adds a summary. No employer, date, personal contact, or personal project is embedded in a template.

The upstream layout is Jake Gutierrez's **Jake's Resume**, MIT licensed, based on sb2nov/resume: <https://www.overleaf.com/latex/templates/jakes-resume/syzfjbzwjncs>. The original MIT notice is preserved in [LICENSE](LICENSE). This renderer is an adaptation, not a byte-identical copy of personal source sections. The reusable preamble is preserved; personal metadata and inputs are replaced by escaped data. The source master's `main.tex` SHA-256 at import was `701174D01AF2568A474618A148C7626611F3C916752884F4896F217277948B01` (verify against the external master before release). Canonical source files remain outside this repository and unchanged.

`renderV5Resume` accepts an explicit `swe` or `data` variant; Auto selection belongs to the later tailoring workflow. The renderer does not select projects or invent prose. M4 must first freeze the exact-five candidate set and apply V5 evidence/composition rules. `fictionalResume` contains five example projects solely for local toolchain testing; example.com links demonstrate PDF hyperlink construction, not verified portfolio repositories.

`renderCoverLetter` supplies a basic one-page layout using explicitly supplied prose. All text is escaped; web hyperlinks require HTTP(S), reject credential-bearing URLs, and encode TeX delimiters. Rendered sources are self-contained apart from standard TeX Live packages and `glyphtounicode`. Compile with pdfLaTeX and shell escape disabled, inspect extracted text and links, and review the actual PDF before treating any output as ready. Rendering alone does not establish evidence accuracy or one-page fit for arbitrary user content.
