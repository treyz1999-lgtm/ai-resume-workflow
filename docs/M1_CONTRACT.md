# M1 implementation contract

M0 pushed at 7bc2ed9 with user approval. M1 local work only until its review gate.

Coordinator owns contracts.ts, Prisma ExecutionRun migration, worker/server.ts, worker/store.ts, integration and tests. Workflow owns worker/codex.ts, worker/rpc.ts, worker/adapters.ts and their tests under src/lib/execution. Infrastructure owns Dockerfile, compose files, worker/latex.ts and tests, worker start script, fictional sample assets and setup docs. Product owns Connections screen, settings navigation, authenticated API proxy and UI/proxy tests. No worker modifies shared schema.

Internal worker listens on port 4310 only in Docker. Every request must carry X-Worker-Token equal to DOSSIER_SECRET; no public worker ports. Web proxy is /api/execution/[...path], requires application session and same-origin mutation checks. Worker URL from WORKER_URL, default http://worker:4310. Only allowlisted operations, no arbitrary process/RPC/URL pass-through. JSON error responses {error:string}; never expose tokens or raw subprocess errors.

Routes: GET /connection -> ConnectionView; POST /login {} -> LoginView; POST /login/cancel {loginId}; POST /logout {}; GET /runs -> RunView[]; POST /runs {model?:string} -> RunView (fixed fictional structured diagnostic only); GET /runs/:id -> RunView; POST /runs/:id/cancel {}; POST /runs/:id/resume {}; POST /latex/sample {} -> LatexArtifact; GET /artifacts/:uuid/sample.pdf or sample.tex. Web returns artifact URLs under /api/execution. Progress is polled from durable output/stage every 1s while running; partial text appears as deltas are saved.

Workflow exports class CodexAdapter implementing ExecutionAdapter, plus connection():Promise<ConnectionView>, login():Promise<LoginView>, cancelLogin(loginId):Promise<void>, logout():Promise<void>, close():void. Constructor default creates managed stdio Codex process. Pin @openai/codex 0.165.0 (resolved registry October 28). Use managed chatgptDeviceCode, force ChatGPT auth, strip API-key env from child, dedicated CODEX_HOME. No host auth copying. Read-only sandbox, never approve tools in diagnostic task, deny unsolicited server requests. Structured output validates diagnostic result; errors typed code auth/quota/cancelled/transport/invalid-result with safe messages. thread checkpoint before turn, thread/resume on retry; only completed turn counts. Preserve partial output, cancel via turn/interrupt. API-compatible and Ollama adapters tested with fake HTTP transports; existing UI providers retained. Do not add external assistant connectors.

Infrastructure exports compileSample(root:string):Promise<{id:string,pages:number,text:string}> and artifactPath(root,id,file):string from worker/latex.ts. Builds ONLY fixed fictional sample at root/:uuid/sample.tex and PDF; no user-supplied TeX in M1. pdflatex -no-shell-escape -halt-on-error; timeout/output limits; pdfinfo + pdftotext check one page/text; errors sanitized. Runtime root /work/artifacts, auth /auth/codex separate managed volume excluded from backups. Need pdflatex packages fontenc/lmodern/geometry/titlesec/enumitem/babel/needspace/hyperref/glyphtounicode, poppler-utils, Chromium retained. Worker entry: yarn prisma generate then yarn tsx worker/server.ts; no worker public port or Docker socket. Worker DB URL and DOSSIER_SECRET env, CODEX_HOME=/auth/codex, EXECUTION_ROOT=/work. No production secrets in images. App migrations before worker store use; coordinator server may retry startup DB connection.

Durability: PostgreSQL ExecutionRun, atomic claim, heartbeat lease, one diagnostic active across workers. Expired runs become INTERRUPTED and require explicit resume. Quota/auth become BLOCKED. Retry same run (no duplicate attempts). Cancellation persists and interrupts active turn. M4 supplies application queue semantics later.

M1 gate: real user sign-in through app and subscription turn; fictional PDF preview/download; fake error/cancellation/quota/recovery tests. If user sign-in is pending, do all independent implementation/checks, clearly report live gate pending. Never claim completion from fixture tests alone.
